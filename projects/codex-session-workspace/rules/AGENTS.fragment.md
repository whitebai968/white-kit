# 文件与产物管理

## 项目与 session 工作区

- 项目是长期容器，每个 session 拥有独立的上下文与文件工作区，路径为 `项目根目录/<session名称>/`。session 内不再增加独立的任务层；普通新会话和分叉各自使用自己的目录，不因目标相同自动合并目录或共享产物。
- 每轮接手、恢复或会话改名后，先按当前会话 ID 定位真实目录，再读 `会话说明.md` 和 `工作/索引.md`；需要追溯时才读原始历史。只读取当前 session 的上下文与文件，跨 session 的读取、引用或复制依据用户指示和明确授权，并登记来源。
- 本机安装了 `~/Library/Application Support/CodexSessionMirror/session_mirror.py` 时，首次使用先读同目录 README 的“定位当前 session”，执行 `python3 "$HOME/Library/Application Support/CodexSessionMirror/session_mirror.py" --locate`。默认使用 `CODEX_THREAD_ID`；没有该环境变量时查明真实 ID 后显式传入。使用返回路径，不凭标题猜测，不用缓存路径重建已改名的旧目录。若返回 archive 且 directory 为空，说明工作区已压缩；先在 Codex 取消归档恢复，不创建同名空目录。
- 同步工具未安装或定位失败时说明情况；能确定归属后才建立临时工作位置并登记，不声称已经自动同步。历史 `codex-file` 和任务绑定属于旧版材料，不再作为新产物默认落点。

## 目录用途与控制权

- `会话说明.md` 由 Agent 维护当前目标、已确认决定、进度、主要文件相对链接和下一步；自动同步信息区由程序维护。`历史记录.jsonl` 是源会话的原始副本，Agent 按需读取，不改写它来替代摘要。
- `资料/` 由用户控制，Agent 默认只读；需要加工时复制所需材料到本 session 的工作组，保留原件。Agent 自行收集的参考材料也先放工作组，用户要求后才移入资料。聊天窗口附件按任务读取使用，不自动复制到资料目录；仅用户明确要求保存时才代为放入。
- `工作/` 是 Agent 默认生成区域，文档、图片、程序源码、配置、测试、候选成品和验证输出都归入本 session 的工作组。程序目录（例如 session-mirror）是具体产物，不作为与资料/工作/成果并列的通用分类。
- `成果/` 由用户选择保留的文件组成；Agent 不因“已完成”或“已验证”自动放入或修改成果。用户明确指示具体文件、版本和目标位置时可代为归档或更新，不重复确认。后续改进默认从认可版本建立新的工作副本。
- 用户明确要求修改已有外部项目文件、正式位置或系统安装目录时，按该次授权操作并在会话说明中登记位置；无需为了目录规则复制第二份正式版。替换前将旧版备份到当前工作组。部署运行和归档成果是独立动作。
- 用户手动新增的文件保持原位；用途和归属明确时补充登记，不能因未出现在索引中就移动、覆盖或删除。

## 工作区组织与索引

- 每批有明确目的的工作使用 `工作/<日期-工作项>/`；同一工作项跨天、跨多轮讨论继续复用，不按每轮或每天重复建组。必要时在组内创建 `验证/`、`临时/`、`备份/`，避免与候选文件混放。
- 生成或调整主要产物、确认重要决定、完成阶段和交付前，更新会话说明与 `工作/索引.md`。索引登记工作项、用途、当前推荐文件和状态，用相对链接定位；依赖、缓存和每个测试中间文件无需逐项登记。
- 状态依据事实：Agent 可标记制作中、已验证、待用户处理；已采用或未采用依据用户决定。只有有实质变化且需比较时保留新版本，避免多个含糊的“最终版”。
- 成果连同必要配图、附件和运行依赖一起交付，避免依赖工作区的临时文件。用户移动文件后检查并更新索引，移动前确认引用不会被破坏。

## 同步、迁移与清理

- 同步工具按 ID 跟踪会话；活跃 session 改名时移动整个同名工作区；归档时校验压缩为项目的 `已归档/<session名称>.zip` 后移除原目录，取消归档时校验解压恢复整个工作区后移除 ZIP，内部相对路径随之保留。归档后改名同时更新 ZIP 名称和包内顶层目录；归档前停止其他进程向工作区写入。项目导航只列会话入口，人工说明写在自动标记区外。
- 分叉继承 Codex 已记录的历史，但不自动复制父会话的工作文件；所需材料按授权复制到自己的工作区并标明来源。目录隔离是协作约定，不等于文件系统权限隔离。
- 源会话删除后同步移除原始历史副本；已有资料、工作文件、成果和编辑过的说明保留，已归档的内容继续以 ZIP 保留。仅未编辑且无产物的自动空模板可随镜像清理，不能扩大为删除整个有内容的 session 目录。
- 交付提供当前工作组、会话入口或候选文件的可点击路径，区分已验证、待用户选择和已归档状态。结束前检查本次生成的文件，将能确认归属且不破坏引用的误放文件移回当前工作组；不明文件先说明。
- 用户定期整理时，按工作组列出用途、状态、是否已有保留成果及引用关系，用户决定后再清理。历史文件不按时间或“看起来无用”自动删除。
