# v1.2.0 · 完整分叉与异常导航

新分叉一次性完整复制父工作区，之后独立；子历史与内部标记使用真实子会话身份。支持从已归档父会话复制、持久事务恢复、已有子工作区保护、内部链接独立化和外部链接拒绝。

项目导航新增同步异常与待处理，即使子工作区尚未创建也显示失败原因。定位命令返回诊断与导航入口，Agent 规则要求每轮接手检查。保留 v1.1.0 的 ZIP 归档、恢复和归档后改名功能。

## 验证

`python3 run_tests.py` 共 76 项隔离测试，含真实后台子进程运行、分叉与 ZIP 往返。发行包须通过清单校验和解压后复测。安装器测试模拟 launchctl；目标机器实际服务启动需独立验收。没有自动创建真实 Codex 用户任务做分叉测试。

## 兼容与限制

- macOS、Python 3.9+、标准库；依赖本机 Codex 的实际原始记录与数据库格式。
- 只对尚无工作区的新分叉执行继承；已有子目录不追溯补拷。
- 父关系取自 forked_from_id，没有信号时无法识别，不根据名称猜测。
- 普通文件独立复制；符号链接、业务路径、复制时间及异常处理见 [分叉说明](FORKING.md)，ZIP 范围见 [归档说明](ARCHIVING.md)。
- 不自动保存聊天附件；不包含个人会话历史、凭据、机器状态和私人备份。
- 目录隔离属于工作约定，不是文件系统权限隔离；没有主动弹窗或唤醒通知。
- 升级前备份代码、规则和状态；有未完成分叉或归档事务时不能直接降级运行旧程序。
