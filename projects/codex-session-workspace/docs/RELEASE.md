# v1.1.0 · ZIP 会话归档

## 本版变化

在 v1.0.0 的独立 session 工作区上增加 ZIP 归档：归档为 `已归档/<session名称>.zip`，校验后清理原目录；取消归档恢复工作区后移除 ZIP；归档后改名同时更新包名与包内目录。项目导航和只读定位入口能识别 ZIP；归档后源历史更新或删除也按既有文件保留规则处理。

新增逐文件哈希、路径与所有权检查、持久事务恢复、同名冲突保护。原有 v1.0.0 归档文件夹升级后自动压缩。聊天附件继续按任务读取，只有用户明确要求保存才放入资料区。

## 验证

运行 `python3 run_tests.py`。56 项测试涵盖既有同步行为、ZIP 往返、空目录/权限/修改时间/符号链接、改名和重名冲突、用户内容保留、损坏包与危险路径、源文件变化、归档和恢复中断。真实后台子进程在临时数据库和目录中完成归档与恢复；安装器和 launchctl 使用模拟环境测试，不改动真实登录服务。

发行文件经校验清单、ZIP 解压复测和 Git 白名单检查。目标电脑的实际 Codex schema、权限、Python 路径和 launchd 启动仍须按安装提示词验收；没有声称在另一台 Mac 已实测安装。制作本包未替换制作电脑的现有后台服务。

## 边界与升级

- macOS、Python 3.9+、标准库；不承诺未来 Codex 内部数据库格式自动兼容。
- 初次只接入显式指定的当前会话，其他旧会话再次活动后接入。Agent 维护说明正文和索引，程序维护同步状态。
- 不自动保存聊天附件；不包含真实历史、私人配置、机器状态、凭证或备份；不自动上传 GitHub。
- ZIP 格式保留普通文件、目录、链接、权限和时间；扩展属性、资源叉、ACL、硬链接关系及特殊文件的边界见 [归档说明](ARCHIVING.md)。归档前应停止其他程序的写入。
- 分叉保持独立；源会话删除后用户内容保留，已归档内容仍为 ZIP。
- 安装升级需备份现有代码与规则；不能直接用旧程序运行含 ZIP 的状态。降级前先在新程序中恢复全部 ZIP 并完成待处理事务，再停服务恢复旧版本。停用使用 `src/install.py stop`，现有文件保留。
